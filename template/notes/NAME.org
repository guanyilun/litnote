* An expensive step, as a tangled script

The reasoning goes here, in prose; the block below stays bare.  It is
tangled (=make tangle=), run outside Emacs, and its output included.

#+begin_src python :tangle @PROJ@/bin/example.py :eval no
import sys
print(sys.argv[1:])
#+end_src

#+begin_src sh :run login :eval no
