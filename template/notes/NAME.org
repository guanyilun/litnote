* An expensive step, as a tangled script

The reasoning goes here, in prose; the blocks stay bare.  A script is
tangled (=make tangle=), run outside Emacs, and its output included.  It is
written in pieces, all tangled to the same file in order, each with its
explanation right above it.

The mean of the arguments, read as numbers: \( \bar{x} = \frac{1}{n} \sum_{i} x_{i} \).

#+begin_src python :tangle @PROJ@/bin/example.py :eval no
import sys


def mean(xs):
    return sum(xs) / len(xs)
#+end_src

The script prints the mean, then one row per argument.  A loop whose body
needs explaining is written as an outline: the loop stays here, and its body
is a named piece, filled in below under its own explanation.

#+begin_src python :tangle @PROJ@/bin/example.py :eval no :noweb yes


xs = [float(a) for a in sys.argv[1:]]
xbar = mean(xs)
print(f"mean {xbar:g}")
for x in xs:
    <<print one value and its deviation>>
#+end_src

Each row is a value \( x_{i} \) and its deviation from the mean,
\( x_{i} - \bar{x} \).

#+name: print one value and its deviation
#+begin_src python :eval no
print(f"{x:8.3f} {x - xbar:+8.3f}")
#+end_src
