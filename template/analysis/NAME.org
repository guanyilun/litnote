* Question and inputs

How does unequal uncertainty affect the combined estimate? We explore
measurements 1 and 2 with standard deviations 1 and 2. The algorithm,
assumptions and checks are explained in [[file:../note/@NAME@.org]].

* Run the example

This script imports the library tangled from the explanatory note. Its
assertions also run on import in this small example. For a larger library,
put automated checks in a separately tangled test module.

#+name: compare-measurements
#+begin_src python :tangle @PROJ@/bin/example.py :eval no
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "src"))
from estimators import weighted_mean

estimate, uncertainty = weighted_mean([1.0, 2.0], [1.0, 2.0])
print(f"estimate {estimate:g}")
print(f"uncertainty {uncertainty:.6f}")
print("checks passed")
#+end_src
